Реализация на C++ стека, двух стеков в одном массиве, кольцевой очереди и дека
на массиве с индексами 1..n — как в псевдокоде учебника (рис. 10.1, 10.2).
Программа печатает состояние массива после каждой операции в стиле рисунков:

```
       1    2    3    4    5    6
S   [  4][  1](  3)(   )(   )(   )
           ^
         S.top = 2
```

`[  4]` — элемент принадлежит структуре (светло-серая ячейка на рисунке),
`(  3)` — значение осталось в массиве, но структуре уже не принадлежит (тёмная ячейка),
`(   )` — в ячейку ещё ничего не записывали.

## Обработка ошибок

Выбран способ **исключения** (как `error "underflow"` в псевдокоде):
- `std::underflow_error("underflow")` — удаление из пустого стека / очереди / дека;
- `std::overflow_error("overflow")` — вставка в заполненный массив;
- `std::invalid_argument` — недопустимый размер массива (n ≤ 0 для стека, n < 2 для очереди и дека).

В демонстрации (`tasks.cpp`) исключения перехватываются и печатаются как `ошибка: ...`.

### 10.1.1 — результат

| Операция | Массив S[1..6] | S.top | Стек |
|---|---|---|---|
| начало | — | 0 | пуст |
| PUSH(S, 4) | 4 | 1 | 4 |
| PUSH(S, 1) | 4 1 | 2 | 4 1 |
| PUSH(S, 3) | 4 1 3 | 3 | 4 1 3 |
| POP(S) → 3 | 4 1 (3) | 2 | 4 1 |
| PUSH(S, 8) | 4 1 8 | 3 | 4 1 8 |
| POP(S) → 8 | 4 1 (8) | 2 | 4 1 |

### 10.1.2 — два стека в одном массиве

Стек 1 начинается в A[1] и растёт вправо (`top1`, пустой — 0), стек 2 начинается в A[n]
и растёт влево (`top2`, пустой — n + 1). Свободное место всегда находится между вершинами,
поэтому переполнение наступает только при `top1 + 1 == top2`, то есть когда в двух стеках
вместе ровно n элементов. PUSH и POP меняют один индекс и одну ячейку — O(1).

### 10.1.3 — результат (Q[1..6], вначале head = tail = 1)

| Операция | Очередь | head | tail |
|---|---|---|---|
| ENQUEUE(Q, 4) | 4 | 1 | 2 |
| ENQUEUE(Q, 1) | 4 1 | 1 | 3 |
| ENQUEUE(Q, 3) | 4 1 3 | 1 | 4 |
| DEQUEUE(Q) → 4 | 1 3 | 2 | 4 |
| ENQUEUE(Q, 8) | 1 3 8 | 2 | 5 |
| DEQUEUE(Q) → 1 | 3 8 | 3 | 5 |

### 10.1.4 — процедуры с проверками

```
QUEUE-EMPTY(Q)  return Q.head == Q.tail
QUEUE-FULL(Q)   return Q.head == Q.tail + 1 or (Q.head == 1 and Q.tail == Q.length)

ENQUEUE(Q, x)                       DEQUEUE(Q)
1 if QUEUE-FULL(Q)                  1 if QUEUE-EMPTY(Q)
2     error "overflow"              2     error "underflow"
3 Q[Q.tail] = x                     3 x = Q[Q.head]
4 if Q.tail == Q.length             4 if Q.head == Q.length
5     Q.tail = 1                    5     Q.head = 1
6 else Q.tail = Q.tail + 1          6 else Q.head = Q.head + 1
                                    7 return x
```

Одна ячейка массива всегда остаётся свободной: если заполнить все n, станет head == tail,
и полную очередь нельзя будет отличить от пустой. Поэтому в Q[1..n] помещается n − 1 элемент.

### 10.1.5 — дек

Кольцевой массив D[1..n], `head` — первый элемент, `tail` — ячейка после последнего.
- PUSH-FRONT: `head = head − 1` (с 1 переходим на n), `D[head] = x`;
- PUSH-BACK: `D[tail] = x`, `tail = tail + 1` (с n переходим на 1);
- POP-FRONT: `x = D[head]`, `head = head + 1`;
- POP-BACK: `tail = tail − 1`, `x = D[tail]`.

Каждая процедура — несколько присваиваний без циклов, O(1). Проверки пустоты и
заполненности те же, что в 10.1.4.

## Проверяемые сценарии (`tests/manual_tests.cpp`)

1. Типичный: последовательность из 10.1.1 даёт стек 4, 1 и S.top = 2; из 10.1.3 — очередь 3, 8, head = 3, tail = 5.
2. Граничный: POP / DEQUEUE / POP-FRONT из пустой структуры → `underflow`.
3. Граничный: PUSH / ENQUEUE / вставка в дек при заполненном массиве → `overflow`.
4. Два стека: один стек может занять почти весь массив, переполнение только при n элементах в сумме.
5. Переход индексов через конец массива (кольцо) в очереди и деке сохраняет порядок элементов.
6. Некорректный размер массива (0 для стека, 1 для очереди) → `invalid_argument`.
